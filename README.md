# 📚 Snap & Study

Snap & Study is an AI-powered study assistant for college students.

## ✨ Features

- Ask study questions using text
- Upload notes, questions, or diagrams
- Get simple explanations using Google Gemini
- Get step-by-step solutions for numerical problems
- Get exam-friendly explanations
- Understand important parts of diagrams

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK
